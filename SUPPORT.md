# Support

- **Bug reports:** use the repository's Bug Report issue template.
- **Feature ideas:** use the Feature Request template.
- **Usage questions:** include the manager version, Windows version and a short description of what you were trying to do.

Please redact Steam API keys, account identifiers, personal paths and other private data before sharing logs.

The application is intended to remain free to use. Voluntary support links may be added by the maintainer after payment-provider and payout eligibility have been verified.
